# QumenX v1.0.0

**Create Without Limits.** QumenX 1.0.0 is the first verified desktop release for Windows 10/11 x64. It is fully local: no accounts, subscriptions, watermarks, cloud services or simulated exports.

## Install

- `QumenX_1.0.0_x64_en-US.msi` — Windows Installer (MSI).
- `QumenX_1.0.0_x64-setup.exe` — NSIS setup wizard.
- `qumenx.exe` — standalone release executable.

Keep the original installer filenames: internal configuration references use them. FFmpeg and FFprobe must be on `PATH` (for example `winget install Gyan.FFmpeg.Essentials`). Export is real FFmpeg H.264/AAC; source media is never modified.

## Highlights

- Multi-track timeline with trim, split, duplicate, group, snapping, keyframes, waveforms and track lock/mute/hide.
- Layered preview with proxies, overlays, text animation, transitions, effects, fades, speed/reverse/freeze and aspect/safe-zone guides.
- Project save/open with versioned JSON, rotating backups (max 12), corrupt-file recovery and backup restore.
- Real FFmpeg export with resolution/FPS/codec/CRF controls, live progress and cancellation.

## Verify

Compare hashes with `releases/windows/checksums/SHA256SUMS.txt`:

```powershell
cd <repo-root>
Get-FileHash -Algorithm SHA256 .\releases\windows\installers\QumenX_1.0.0_x64_en-US.msi
```

Full verification details: [documentation/verification-report.md](../../documentation/verification-report.md).

## Known limitations

- Concurrent native exports are not supported: the Rust backend uses a process-wide cancel flag. The UI serializes exports.
- The non-fatal `.rsrc merge failure: multiple non-default manifests` linker warning can appear with the GNU toolchain; the app builds, launches and exports correctly.
